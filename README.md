# kitaptakip1

Kitapyurdu üzerinden kitap arayan, rafları ve okuma ilerlemesini takip eden Flask uygulaması.

## Kurulum

```powershell
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python application.py
```

Giriş bilgileri: `test` / `123`

## Docker

```powershell
docker compose up -d --build
```

Uygulama: http://localhost:5010
